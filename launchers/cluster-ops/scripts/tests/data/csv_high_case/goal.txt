Create a Python module with parse_csv(text) -> list of lists of str, without using the csv module. Fields are separated by commas and records by '\n' or '\r\n'. A field that starts with '"' is quoted: inside it, '""' is one literal quote and commas and line breaks are literal; after its closing quote only a comma, a line break or the end of the text may follow, otherwise raise ValueError. An unquoted field is taken literally up to the next comma or line break (a '"' inside it is an ordinary character). An unterminated quoted field raises ValueError. A line break at the very end doesn't start another record; an empty line elsewhere is a record with no fields ([]). An empty text gives []. Command line: python <script> FILE prints each record as a Python list. In --test mode check quoting, escaped quotes, line breaks inside quotes, CRLF, empty fields, empty lines and the errors.
