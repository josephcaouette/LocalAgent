Import: from csv_high import parse_csv. parse_csv(text: str) -> list[list[str]] parses CSV without the csv module. Line breaks are LF or CRLF; a lone CR is ordinary. It returns [] for empty text; a trailing line break does not add a record; an empty line produces []; a line with commas produces empty fields. Raises ValueError for an unterminated quoted field or for any character after a closing quote other than comma, LF, CRLF, or end of text. CLI: python3 csv_high.py FILE reads FILE as UTF-8 with newline preservation, prints one line per record using Python list repr, and exits 0; on file or parse error prints a message to stderr and exits 1. python3 csv_high.py --test runs built-in self-tests, prints one PASS <case> line per case for quoting, escaped_quotes, line_breaks_inside_quotes, crlf, empty_fields, empty_lines, errors, then OK, and exits 0; on any failure prints FAIL <case> and exits 1. With no arguments or unknown arguments it prints usage to stderr and exits 2.
